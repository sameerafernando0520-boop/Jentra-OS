08 / INTERACTION & ACCESS

Confidence is in
the small things.

Accessibility is part of the design language. Deliberate focus, legible information and predictable behavior make the whole system easier to use.

01

Clarity in every state

Text and symbols carry status. Labels persist. Errors explain the problem and the next useful step.

02

A complete keyboard path

Visible focus, logical order, arrow-key tabs and Escape to dismiss dialogs. Return focus to the action that opened an overlay.

03

Motion that respects you

120 ms for a small response, 180 ms for a standard transition, 240 ms for a panel. Respect reduced-motion preferences.

04

Precision without friction

Right-align amounts. Make currency explicit. Preserve exact financial values. Use concise human language for every outcome.

Built with accessibility in mind.

WCAG 2.2 AA is the product target. Contrast, keyboard access, 200% text scaling and actual desktop rendering remain release checks.
